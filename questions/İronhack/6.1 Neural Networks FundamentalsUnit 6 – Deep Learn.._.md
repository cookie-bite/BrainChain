## From Linear Models to Neurons

Think back to logistic regression from Unit 4.1. Given an input vector $x$, you computed a score $z = w^Tx + b$, squashed it through a sigmoid, and got a probability:

$$\hat{y} = \sigma(w^Tx + b)$$

That is a single artificial neuron. Really. The "neurons" in deep learning are mathematically just regression units with a non-linear function on top.

So why all the hype? Because once you start stacking these units — the output of one neuron becomes the input of another — something remarkable happens. The model can learn representations of the data that are far richer than any single linear boundary could capture. That's the entire trick of deep learning, condensed into a single sentence.

### Anatomy of a Neuron

A neuron does three things, in order:

1. Compute a weighted sum of its inputs plus a bias: $z = \sum_{i} w_ix_i + b$
2. Apply a non-linear activation function $a = f(z)$
3. Pass the result $a$ to whatever neuron(s) come next

```
   x1 ──w1──┐
   x2 ──w2──┼── Σ ──► z ──► f(z) ──► a
   x3 ──w3──┘    +b

```

The weights $w_i$ and the bias $b$ are what the network learns. The activation function $f$ is something you choose. Everything else in deep learning is just clever ways to organise lots of these neurons and train them efficiently.

## The Multi-Layer Perceptron (MLP)

Now let's stack neurons into a real network. The simplest useful architecture is the Multi-Layer Perceptron — a fully connected feedforward network. "Feedforward" just means information flows in one direction: input $\rightarrow$ output, never backwards.

A typical MLP has three kinds of layers:

* **Input layer** — one node per feature in your data; doesn't compute anything, just holds values
* **Hidden layer(s)** — the workhorses; each neuron in a hidden layer is fully connected to every neuron in the previous layer
* **Output layer** — produces the final prediction; its size depends on the task (1 for regression, $K$ for $K$-class classification)

```
   Input          Hidden 1         Hidden 2         Output
   (3 units)      (4 units)        (3 units)        (2 units)
   x ∈ ℝ³         h⁽¹⁾ ∈ ℝ⁴       h⁽²⁾ ∈ ℝ³        ŷ ∈ ℝ²

       ●              ●                ●
   x1 ─┼──────────────●────────────────●────────────────●─── ŷ1
   x2 ─┼─── FC ───────●────── FC ──────●────── FC ──────●─── ŷ2
   x3 ─┼──────────────●────────────────●
       ●              ●

                     W⁽¹⁾ + b⁽¹⁾      W⁽²⁾ + b⁽²⁾      W⁽³⁾ + b⁽³⁾
                  (4×3 + 4 = 16)   (3×4 + 3 = 15)   (2×3 + 2 = 8)

```

> **Architecture Layout:** Each "FC" path denotes a fully-connected (dense) layer. Every node on the left maps a learned weight to every node on the right. The $W$ matrices and $b$ vectors represent the numbers the network optimizes over time.

Notice that each layer is essentially a matrix multiplication followed by an activation:

$$h^{(1)} = f(W^{(1)}x + b^{(1)})$$

$$h^{(2)} = f(W^{(2)}h^{(1)} + b^{(2)})$$

$$\hat{y} = g(W^{(3)}h^{(2)} + b^{(3)})$$

Where $W^{(\ell)}$ is the weight matrix for layer $\ell$, $b^{(\ell)}$ is the bias vector, $f$ is the hidden-layer activation, and $g$ is whatever the output task needs (sigmoid for binary classification, softmax for multi-class, identity for regression).

### Why Stack Layers?

Each layer learns a transformation of its inputs. The first layer might learn simple combinations of raw features. The next layer combines those into higher-level patterns. By the time you reach the output, the network has built up a representation that makes the prediction task much easier than it was on raw data.

For an image classifier, this is intuitive. Early layers detect edges and colour blobs, middle layers detect textures and parts (an eye, a wheel), and late layers detect whole objects (a cat, a car). For tabular data the layers are less interpretable but the principle is the same: the network is constructing useful features automatically — no manual feature engineering required.

## Activation Functions: The Source of Expressiveness

If a neuron is just a linear combination, isn't a stack of neurons still linear?

Yes — and that's exactly the problem. A composition of linear functions is itself a linear function. Without non-linear activations, no matter how many layers you stack, the network can only represent linear decision boundaries. The activation function is what gives neural networks their power.

Let's meet the most important ones.

### Sigmoid

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Squashes any real number into $(0, 1)$. Beautiful in theory, problematic in deep networks: when $|z|$ is large, $\sigma'(z) \approx 0$, which causes the vanishing gradient problem during training.

Today's takeaway: still useful in the output layer for binary classification, rarely a good choice in hidden layers.

### Tanh

$$\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$$

A scaled and shifted sigmoid that maps to $(-1, 1)$. Centred around zero, which helps optimisation a little, but suffers from the same saturation issues as sigmoid.

### ReLU (Rectified Linear Unit)

$$\text{ReLU}(z) = \max(0, z)$$

The default choice for hidden layers in modern deep learning. It's cheap to compute, doesn't saturate for positive inputs, and works astonishingly well in practice. Almost every deep architecture you'll meet — CNNs, MLPs, even parts of transformers — uses ReLU or one of its variants.

It does have one quirk: if a neuron's input is always negative, its gradient is exactly zero forever. The neuron "dies" and stops learning. Variants like Leaky ReLU and GELU address this by letting a small gradient flow even for negative inputs.

### Softmax (Output Only)

$$\text{softmax}(z)_i = \frac{\exp(z_i)}{\sum_{j} \exp(z_j)}$$

For multi-class classification: turns a vector of raw scores into a probability distribution that sums to 1. Used only in the output layer — never as a hidden activation.

### Quick Comparison

| Activation | Range | Where to use | Watch out for |
| --- | --- | --- | --- |
| **Sigmoid** | $(0, 1)$ | Binary output | Vanishing gradients |
| **Tanh** | $(-1, 1)$ | Sometimes RNNs | Saturation |
| **ReLU** | $[0, \infty)$ | Default for hidden layers | Dead neurons |
| **Leaky ReLU** | $(-\infty, \infty)$ | Drop-in for ReLU | Slightly slower |
| **Softmax** | Probabilities | Multi-class output | Numerical stability |

A reasonable starting recipe: ReLU in every hidden layer, softmax/sigmoid/identity in the output layer to match the task. You can tune this later — but you almost never go wrong starting here.

## Forward Propagation by Hand

The best way to demystify neural networks is to compute one. Let's run a forward pass on a tiny network with two inputs, one hidden layer of two neurons (ReLU), and one output (sigmoid):

Inputs: $x = [1.0, 2.0]$

Hidden layer weights:


```
W1 = np.array([[0.5, -0.4],
              [0.3, 0.8]])
b1 = np.array([[0.1],
              [-0.2]])
```

Output layer weights:


```
W2 = np.array([[0.6, -0.5]])
b2 = 0.1
```

**Step 1 — pre-activation of the hidden layer:**

$$z^{(1)} = W^{(1)}x + b^{(1)} = \begin{bmatrix} 0.5(1) + (-0.4)(2) + 0.1 \\ 0.3(1) + (0.8)(2) + (-0.2) \end{bmatrix} = \begin{bmatrix} -0.2 \\ 1.7 \end{bmatrix}$$

**Step 2 — ReLU activation:**

$$h^{(1)} = \max(0, z^{(1)}) = \begin{bmatrix} 0 \\ 1.7 \end{bmatrix}$$

The first hidden neuron just "died" for this input. That's fine — the second one still carries the signal.

**Step 3 — output pre-activation:**

$$z^{(2)} = W^{(2)}h^{(1)} + b^{(2)} = 0.6(0) + (-0.5)(1.7) + 0.1 = -0.75$$

**Step 4 — sigmoid output:**

$$\hat{y} = \sigma(-0.75) \approx 0.32$$

So our model says class 1 has probability $\approx 0.32$, meaning class 0 is more likely. That's it. That is what every neural network does, just with bigger matrices and more layers.

## Building Our First Network in PyTorch

Enough whiteboard. Let's build a real (if tiny) network. PyTorch is the framework you'll use throughout this unit because it's the de facto standard in research and industry.


```
import torch
import torch.nn as nn

class TinyMLP(nn.Module):
    def __init__(self, n_inputs=2, n_hidden=4, n_outputs=1):
        super().__init__()
        self.fc1 = nn.Linear(n_inputs, n_hidden)
        self.fc2 = nn.Linear(n_hidden, n_outputs)

    def forward(self, x):
        h = torch.relu(self.fc1(x))
        out = torch.sigmoid(self.fc2(h))
        return out

model = TinyMLP()
x = torch.tensor([[1.0, 2.0]])
y_hat = model(x)
print(y_hat)
```

Three things to notice:

1. The class inherits from `nn.Module`. That's PyTorch's universal building block — every model, every layer, every loss function is one.
2. `nn.Linear(in, out)` creates a fully-connected layer with both weights and bias initialised for you.
3. `forward()` defines what happens when you call `model(x)`. PyTorch automatically tracks every operation here so it can compute gradients later.

The output won't be meaningful — the weights are random — but the plumbing is real. Tomorrow we'll teach this network to actually learn something.

## Why Depth Matters

You might wonder: if a wide enough single-hidden-layer network can approximate any continuous function (a famous theoretical result called the Universal Approximation Theorem), why bother with depth?

The answer is practical efficiency. Deep networks compose simple transformations into rich ones using exponentially fewer parameters than shallow networks need to express the same function. A deep network is like a compact recipe; a shallow one is like a phone book of every possible input-output pair. Both can in principle represent the same thing, but only one is learnable from finite data.

This is why modern architectures are deep: image models with 50, 100, sometimes hundreds of layers; language models with even more. Depth, used wisely, gives you generalisation power that width alone cannot match.

### A Mental Model: Networks as Differentiable Programs

A neural network is a parameterised, differentiable program. You define the structure (layers, activations, connections), pick the parameters that match the data (training), and run the program forward to make predictions.

The reason deep learning works at all is that this program is differentiable end-to-end. We can compute, exactly, how a tiny change in any one weight would change the final loss. That's the magic that makes gradient-based learning possible — and that's the topic of tomorrow's lesson.

## Summary

Today you turned the abstract idea of "neural networks" into something concrete:

* An artificial neuron is a weighted sum followed by a non-linear activation.
* A Multi-Layer Perceptron is just neurons stacked in fully-connected layers, with the output of one feeding into the next.
* Activation functions are what stop a deep network from collapsing into a glorified linear regression. ReLU is the modern default for hidden layers.
* Forward propagation is the matrix-multiply-then-activate dance that turns inputs into predictions.
* Depth matters because it lets a network represent rich functions with far fewer parameters than width alone could manage.
* PyTorch makes building these models surprisingly compact. In the lab today you'll go from theory to practice: implement an MLP from scratch in NumPy first (so the maths is real, not magical), then rebuild the same network in PyTorch and compare.
