# pandas Foundations: Series, DataFrame, and Indexing

## Introduction

When your data moves beyond small numeric arrays and into labeled, heterogeneous tables, you need a structure that understands labels, aligns data automatically, and gives you precise control over missing values. pandas provides that structure. Its two core objects, Series and DataFrame, are designed to represent labeled one-dimensional and two-dimensional data, respectively. This lesson builds the mental model for how these objects work, how indexing and alignment behave, and why those behaviors are essential in real data analysis workflows.

You will see how labels make your code more expressive, how pandas aligns on index and column names, and how different indexing styles change the meaning of your code. By the end, you should be able to create Series and DataFrames, select and filter data safely, and reason about what pandas is doing under the hood when it merges, slices, or aligns.

## Series: A Labeled One-Dimensional Array

A Series is like a one-dimensional array with an index. The index provides labels for each value, and those labels are as important as the values themselves. The mental model is that a Series is a mapping from label to value with array-like operations layered on top.

You can create a Series from a list:


```
import pandas as pd

temps = pd.Series([21.1, 22.4, 20.8, 19.9], name="temperature_c")
temps
```

By default, pandas assigns an integer index starting at 0. You can also supply your own labels:


```
temps_by_day = pd.Series([21.1, 22.4, 20.8, 19.9], index=["Mon", "Tue", "Wed", "Thu"])
temps_by_day
```

Now the index carries meaning. You can access values by label:


```
temps_by_day["Tue"]
```

This label-based access is a core pandas feature. It makes code resilient to changes in order, and it makes your intent clear. If the data is reordered, label-based selection still returns the correct value.

Series also behave like arrays for vectorized operations:


```
temps_by_day + 1.5
```

The scalar is added to each element. This is elementwise computation similar to NumPy, but the labels remain attached to the values. This is one of pandas' strengths: you can compute like NumPy while preserving labels.

## Index Objects and Alignment

The index is more than a set of labels; it is an object that controls how data aligns. When you perform arithmetic between two Series, pandas aligns on index labels rather than on position.


```
temps_city_a = pd.Series([21.1, 22.4, 20.8], index=["Mon", "Tue", "Wed"])
temps_city_b = pd.Series([19.9, 23.0, 21.0], index=["Tue", "Wed", "Thu"])

temps_city_a + temps_city_b
```

The result has labels Mon, Tue, Wed, and Thu. Values are aligned by label: Tue and Wed are added, while Mon and Thu become missing because one Series lacks those labels. This behavior is essential for correctness in real analysis, where datasets often have different coverage. Instead of silently matching by position, pandas makes mismatches explicit through missing values.

Understanding alignment helps you interpret results correctly. If you see unexpected missing values after an operation, it is often because the labels did not overlap as you assumed. Checking the index is a quick way to diagnose those issues.

## DataFrames: Labeled Two-Dimensional Data

A DataFrame is a two-dimensional table with labeled rows and columns. You can think of it as a collection of aligned Series sharing the same row index. Each column is a Series, and the column names provide semantic meaning.

Here is a simple DataFrame:


```
data = {
    "city": ["Seoul", "Berlin", "Nairobi", "Toronto"],
    "temperature_c": [26.5, 18.2, 22.1, 16.7],
    "humidity": [0.60, 0.65, 0.58, 0.70]
}

df = pd.DataFrame(data)
df
```

The columns are labeled, and the rows have a default integer index. You can access a column by name:


```
df["temperature_c"]
```

This returns a Series. The DataFrame is not just a matrix; it is a labeled structure with mixed types and rich semantics. This is why pandas is a natural fit for real-world data.

You can also set a column as the index:


```
df_indexed = df.set_index("city")
df_indexed
```

Now city becomes the row index, which can make selection more meaningful if you treat cities as unique identifiers. The index is a first-class part of the structure, not just a row counter.

## Indexing and Selection: loc, iloc, and Boolean Masks

pandas offers multiple ways to select data. The most important distinction is between label-based indexing and position-based indexing. The mental model is that `loc` uses labels, while `iloc` uses integer positions.


```
df.loc[0]
```

This uses the label 0 in the index, which is the default label for the first row. If you set a different index, `loc` would use those labels instead. `iloc` uses numeric positions:


```
df.iloc[0]
```

This always returns the first row, regardless of index labels. This distinction matters when your index is not a simple range. If you use `iloc` when you intend label-based selection, you may silently select the wrong rows. The safest practice is to use `loc` for labels and `iloc` for positions, and to be explicit about which you want.

Boolean masks are another powerful selection method:


```
df[df["temperature_c"] > 20]
```

This returns only rows where the temperature exceeds 20. The expression `df["temperature_c"] > 20` creates a boolean Series aligned to the DataFrame's index. pandas uses that mask to filter rows. This is a natural pattern for data cleaning and exploration because it reads like a logical statement.

You can combine conditions with `&` and `|`:


```
df[(df["temperature_c"] > 20) & (df["humidity"] < 0.65)]
```

The parentheses are required because `&` has higher precedence than comparison operators. This is a subtle but important detail for correctness, and it is part of the mental model you need when building complex filters.

## Assigning Data and Alignment in DataFrames

Assignment in pandas is also label-aware. If you assign a Series to a DataFrame column, pandas aligns on the index. This can be powerful but also surprising if you are not expecting it.


```
adjustments = pd.Series([1.0, -0.5], index=[0, 2])
df["adjusted_temp"] = df["temperature_c"] + adjustments
df
```

Only rows with matching indices receive the adjustment. Others become missing. This is consistent with Series alignment, but it can surprise you if you expected positional behavior. If you want position-based assignment, you can use `.values` or `.to_numpy()` to remove labels, but you should do so deliberately because it discards alignment information.

## Handling Missing Data

Missing data is common in real datasets, and pandas represents missing values with `NaN`. Many operations propagate `NaN`, which is usually what you want because it prevents silent errors. You can check for missing values with `isna` and `notna`:


```
df["adjusted_temp"].isna()
```

To fill missing values, use `fillna`:


```
df["adjusted_temp"] = df["adjusted_temp"].fillna(df["temperature_c"])
df
```

This replaces missing adjusted temperatures with the original temperatures. The important mental model is that missing values are explicit and contagious unless you handle them. This makes the data quality visible rather than hidden, which is critical for trustworthy analysis.

## Sorting and Reindexing

Sorting in pandas can apply to the index or to values. Sorting by values is common in analysis for ranking or ordering results:


```
df.sort_values("temperature_c")
```

Sorting by index is useful when you want to align with other datasets or impose a logical order:


```
df.sort_index()
```

Reindexing lets you conform a DataFrame to a specific index, which can introduce missing values if some labels are absent:


```
new_index = ["Nairobi", "Toronto", "Seoul", "Berlin", "Madrid"]
df_indexed.reindex(new_index)
```

This creates a new DataFrame that includes Madrid with missing values. Reindexing is a deliberate operation, and it is often used to align data from different sources before combining or comparing.

## Combining Series and DataFrames

pandas provides many ways to combine data. At this stage, the key mental model is that alignment by labels is the default and that you can choose how to handle mismatches. Concatenation stacks objects along an axis, while arithmetic aligns and preserves labels.

For example, concatenating two Series:


```
temps_a = pd.Series([21.1, 22.4], index=["Mon", "Tue"])
temps_b = pd.Series([20.8, 19.9], index=["Wed", "Thu"])

pd.concat([temps_a, temps_b])
```

The result is a longer Series. When you concatenate DataFrames, you can stack rows or columns depending on the axis. The default is to stack rows. If you concatenate along columns, pandas aligns on the index. This alignment behavior is consistent across pandas operations, which makes it predictable once you internalize the rule.

## Putting the Concepts Together

pandas is built on the idea that labels carry meaning. Series and DataFrames are not just containers; they are labeled data structures that preserve semantics. Index alignment gives you correctness when merging or computing across datasets, and indexing methods let you control whether you are selecting by label or by position. Missing data is explicit, which forces you to reason about data quality rather than ignore it.

When you approach analysis with these mental models, pandas becomes a powerful ally. You can manipulate datasets confidently, knowing how alignment will behave. You can slice and filter with intent, and you can build transformations that remain correct even as the data changes shape or order. These foundations are essential for any serious data analysis or AI work.
