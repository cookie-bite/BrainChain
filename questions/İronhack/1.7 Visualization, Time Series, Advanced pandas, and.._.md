## Visualization as a Thinking Tool

Visualization is not just for presentation; it is a form of analysis. The key is to design plots that match the question. Line plots are good for trends, bar charts for comparisons, scatter plots for relationships, and histograms for distributions. With pandas, you can generate these quickly and integrate them into your data workflow.

Suppose you have daily sales data:


```
import pandas as pd

sales = pd.DataFrame({
    "date": pd.date_range("2024-01-01", periods=7, freq="D"),
    "sales": [120, 130, 125, 160, 150, 170, 165]
}).set_index("date")

sales.plot()
```

This produces a line plot of sales over time. The index is the x-axis because it is a `DateTimeIndex`. This is a simple example, but it illustrates the principle: if your data is indexed by time, pandas will naturally give you a time-aware plot.

For comparisons across categories, you might use a bar chart:


```
by_city = pd.Series({"Seoul": 26.5, "Berlin": 18.2, "Nairobi": 22.1})
by_city.plot(kind="bar")
```

Choosing the plot type is part of the reasoning process. A line chart for categorical comparisons can be misleading, while a bar chart for time trends can hide the continuity of change. The visualization should match the semantics of the data.

## Time Series Basics and DateTimeIndex

Time series analysis begins with properly typed dates. When your index is a `DateTimeIndex`, pandas provides time-aware slicing and resampling. This changes how you think about filtering data.


```
ts = pd.Series(
    [120, 130, 125, 160, 150, 170, 165],
    index=pd.date_range("2024-01-01", periods=7, freq="D")
)

ts["2024-01-03":"2024-01-05"]
```

This slices by date string, which pandas interprets as a date range. This label-based time slicing is one of the most powerful features of pandas for time series work. You can also select by year or month:


```
monthly = ts["2024-01"]
```

This selects all values from January 2024. The mental model is that the index is not just labels; it is a time-aware structure that supports semantic slicing.

## Resampling and Frequency Conversion

Resampling changes the frequency of a time series. It is useful when you need to aggregate daily data into monthly summaries or interpolate missing timestamps. The key is that resampling is `groupby` for time.


```
weekly = ts.resample("W").sum()
weekly
```

Here, `"W"` indicates weekly frequency. The data is grouped into weeks, and the sum is computed for each. You can also take means, counts, or other aggregations. If you need a finer frequency, you can upsample and fill:


```
hourly = ts.resample("H").ffill()
```

This forward-fills values to hourly frequency. The choice of method depends on the meaning of your data. For cumulative values like sales, summing is natural. For measurements like temperature, averaging might be more appropriate.

## Rolling Windows and Moving Statistics

Rolling operations let you compute statistics over a moving window, which is essential for smoothing and trend detection. The mental model is that you slide a window across time and compute a statistic at each step.


```
rolling_mean = ts.rolling(window=3).mean()
rolling_mean
```

This computes a 3-day moving average. The first two values are missing because there are not enough points to fill the window. You can choose to set `min_periods` if you want earlier values, but you should do so carefully because it changes the meaning of the statistic.

Rolling statistics are common in financial analysis, monitoring, and signal processing. They let you separate noise from signal and detect shifts in behavior.

## Time Zone Awareness and Localization

Time zones can introduce subtle errors if you ignore them. pandas supports timezone-aware timestamps, which is critical when you work with data from multiple regions or sources.


```
ts_utc = ts.tz_localize("UTC")
ts_seoul = ts_utc.tz_convert("Asia/Seoul")
```

Localization sets the time zone for naive timestamps, while conversion changes the representation to a different zone. The important idea is to be explicit about time zones so that comparisons and merges across datasets remain correct.

## Advanced pandas: Categorical Data

Categorical data often has a small set of repeated values. pandas provides a categorical `dtype` that is more memory-efficient and allows explicit category ordering.


```
df = pd.DataFrame({
    "priority": ["low", "medium", "high", "medium", "low"]
})

df["priority"] = pd.Categorical(df["priority"], categories=["low", "medium", "high"], ordered=True)
df["priority"].dtype
```

This sets an ordered categorical type. Now comparisons and sorting follow the defined order rather than alphabetical order. This is especially important when categories have a natural ranking.

## Advanced pandas: String Methods and Vectorized Text

String processing is common in data cleaning and feature extraction. pandas exposes vectorized string methods through `.str`, which apply operations across an entire Series.


```
names = pd.Series(["  Seoul  ", "Berlin", "NAIROBI"])
clean = names.str.strip().str.title()
clean
```

This removes whitespace and standardizes capitalization. The operations are vectorized, which keeps the code concise and efficient.

## Advanced pandas: Apply, Map, and Vectorization

You often need custom transformations. pandas provides `map` for Series and `apply` for Series or DataFrames. The mental model is that `map` is for elementwise transforms on a Series, while `apply` is for row- or column-wise transforms.


```
temps = pd.Series([21.1, 22.4, 20.8])
temps_f = temps.map(lambda x: x * 9 / 5 + 32)
temps_f
```

For DataFrames:


```
df = pd.DataFrame({"a": [1, 2], "b": [3, 4]})
row_sums = df.apply(lambda row: row["a"] + row["b"], axis=1)
row_sums
```

These tools are flexible, but vectorized operations are usually faster. You should reach for `map` or `apply` when a vectorized approach is not obvious or when the transformation is genuinely custom.

## Advanced pandas: Hierarchical Indexing

Hierarchical indexes let you represent multi-dimensional data in a single object. This is common after `groupby` operations or when you stack multiple datasets.


```
data = pd.DataFrame({
    "city": ["Seoul", "Seoul", "Berlin", "Berlin"],
    "month": ["Jan", "Feb", "Jan", "Feb"],
    "sales": [120, 130, 95, 100]
})

indexed = data.set_index(["city", "month"])
indexed
```

You can access with multi-level keys:


```
indexed.loc[("Seoul", "Jan")]
```

You can also reshape with `unstack`:


```
wide = indexed["sales"].unstack("month")
wide
```

This pattern is powerful for building summary tables without losing the structure of your data.

## Modeling with pandas and NumPy

While pandas is not a modeling library, it is often used to prepare data for modeling and to evaluate results. A simple modeling workflow might involve splitting data, fitting a linear model, and checking errors.

Here is a minimal example using NumPy for linear regression:


```
import numpy as np

df = pd.DataFrame({
    "x": [1, 2, 3, 4, 5],
    "y": [2.1, 3.9, 6.2, 7.8, 10.1]
})

X = np.column_stack([np.ones(len(df)), df["x"]])
y = df["y"].to_numpy()

beta = np.linalg.lstsq(X, y, rcond=None)[0]
beta
```

The `lstsq` function returns coefficients for a linear model that minimizes squared error. This example shows the connection between pandas and NumPy: pandas handles data structure, and NumPy handles numerical computation. You can then generate predictions:


```
pred = X @ beta
pred
```

And compute residuals:


```
residuals = y - pred
residuals
```

This is not a full modeling pipeline, but it demonstrates the workflow: structure data, fit a model, evaluate errors. The key is to keep data aligned and to interpret results in context.
